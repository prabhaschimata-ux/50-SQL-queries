# 50 SQL Queries Using Two Tables

## Project Description

This project contains 50 SQL queries based on two related tables: **Employee** and **Department**. It demonstrates the use of SQL commands for database creation, data manipulation, data retrieval, joins, aggregate functions, grouping, sorting, filtering, and table modification.

## Tables Used

### Employee
- EmpID
- EmpName
- Age
- Gender
- Salary
- DeptID

### Department
- DeptID
- DeptName
- Location

## SQL Concepts Covered

- CREATE TABLE
- INSERT INTO
- SELECT
- WHERE
- ORDER BY
- DISTINCT
- LIKE
- BETWEEN
- IN
- Aggregate Functions (COUNT, SUM, AVG, MAX, MIN)
- GROUP BY
- HAVING
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Subqueries
- UPDATE
- DELETE
- ALTER TABLE
- SHOW TABLES
- DESC
